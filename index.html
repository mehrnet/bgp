Public API

Build with Mehr BGP

JSON over HTTPS, no API key required. Responses are served from the daily materialized BGP dataset.

Base URL https://bgp-api.mehrnet.com All endpoints return JSON. Set Accept: application/json when your client does not do so by default.
Endpoints

Lookup resources

GET /v1/meCurrent connection address
GET /v1/ip/{address}IPv4 or IPv6 address
GET /v1/prefix?prefix={cidr}Allocation and registered route objects
GET /v1/range?start={ip}&end={ip}Overlapping allocations
GET /v1/range?...&kind=routesOverlapping registered routes
GET /v1/asn/{asn}Aut-num record and routes
GET /v1/search?q={query}Normalize an IP, CIDR, or ASN
GET /v1/healthService health

Prefix, range, and ASN endpoints accept limit from 1 to 100 and return next_cursor when another page is available.

Examples

Request an IP record

Shell

Curl

curl -sS https://bgp-api.mehrnet.com/v1/ip/1.1.1.1
Browser or Node.js

JavaScript

const response = await fetch(
  "https://bgp-api.mehrnet.com/v1/ip/1.1.1.1"
);
const data = await response.json();
PHP cURL

PHP

$curl = curl_init("https://bgp-api.mehrnet.com/v1/ip/1.1.1.1");
curl_setopt($curl, CURLOPT_RETURNTRANSFER, true);
$data = json_decode(curl_exec($curl), true);
