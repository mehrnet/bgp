Public API

Build with Mehr BGP

JSON over HTTPS, no API key required. Responses are served from the daily materialized BGP dataset.

Base URL https://bgp-api.mehrnet.com All endpoints return JSON. Lookup responses include meta.dataset; health also reports the running binary build. OpenAPI JSON
Endpoints

Lookup resources

GET /v1/meCurrent connection address
GET /v1/ip/{address}IPv4 or IPv6 address
GET /v1/prefix?prefix={cidr}Allocation and registered route objects
GET /v1/range?start={ip}&end={ip}Overlapping allocations
GET /v1/range?...&kind=routesOverlapping registered routes
GET /v1/asn/{asn}Aut-num record and routes
GET /v1/search?q={query}Normalize an IP, CIDR, or ASN
GET /v1/healthService health and active dataset metadata

Prefix, range, and ASN endpoints accept limit from 1 to 100 and return next_cursor when another page is available. IP and current-connection lookups accept details=full when raw matched records are needed. Direct RPSL abuse-c and abuse-mailbox values are returned as abuse_contact when present in the daily dataset.

Examples

Lookup examples

Current connection

Return the address seen by the API and its BGP, allocation, and geofeed record.

curl -sS "https://bgp-api.mehrnet.com/v1/me"
const response = await fetch("https://bgp-api.mehrnet.com/v1/me");
const data = await response.json();
$json = file_get_contents("https://bgp-api.mehrnet.com/v1/me");
$data = json_decode($json, true);
from urllib.request import urlopen
import json

data = json.load(urlopen("https://bgp-api.mehrnet.com/v1/me"))

CIDR prefix lookup

Inspect the allocation covering a prefix and the registered route objects that overlap it.

curl -sS "https://bgp-api.mehrnet.com/v1/prefix?prefix=1.1.1.0%2F24&limit=10"
const url = new URL("https://bgp-api.mehrnet.com/v1/prefix");
url.searchParams.set("prefix", "1.1.1.0/24");
url.searchParams.set("limit", "10");
const data = await (await fetch(url)).json();
$url = "https://bgp-api.mehrnet.com/v1/prefix?prefix=" . rawurlencode("1.1.1.0/24") . "&limit=10";
$data = json_decode(file_get_contents($url), true);
from urllib.parse import urlencode
from urllib.request import urlopen
import json

query = urlencode({"prefix": "1.1.1.0/24", "limit": "10"})
data = json.load(urlopen(f"https://bgp-api.mehrnet.com/v1/prefix?{query}"))

Range lookup

Find allocations or route objects that overlap a start and end address.

curl -sS "https://bgp-api.mehrnet.com/v1/range?start=1.1.1.0&end=1.1.1.255&kind=routes&limit=10"
const url = new URL("https://bgp-api.mehrnet.com/v1/range");
url.searchParams.set("start", "1.1.1.0");
url.searchParams.set("end", "1.1.1.255");
url.searchParams.set("kind", "routes");
const data = await (await fetch(url)).json();
$params = http_build_query([
  "start" => "1.1.1.0",
  "end" => "1.1.1.255",
  "kind" => "routes",
  "limit" => "10",
]);
$data = json_decode(file_get_contents("https://bgp-api.mehrnet.com/v1/range?" . $params), true);
from urllib.parse import urlencode
from urllib.request import urlopen
import json

query = urlencode({"start": "1.1.1.0", "end": "1.1.1.255", "kind": "routes", "limit": "10"})
data = json.load(urlopen(f"https://bgp-api.mehrnet.com/v1/range?{query}"))
