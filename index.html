Public API / field manual

Trace the network.

One public API for address, prefix, range, and ASN intelligence. JSON over HTTPS, built from MehrNet's daily routing dataset.

Base URL https://bgp-api.mehrnet.com No key, no client library. Lookup responses include meta.dataset so every answer can be traced to its source build. OpenAPI JSON
Endpoints

Lookup resources

GET/v1/meCurrent connection address GET/v1/ip/{address}IPv4 or IPv6 address GET/v1/prefix?prefix={cidr}Allocation and registered route objects GET/v1/range?start={ip}&end={ip}Overlapping allocations or routes GET/v1/asn/{asn}Aut-num record and registered routes GET/v1/search?q={query}Normalize an IP, CIDR, or ASN

Prefix, range, and ASN endpoints accept limit from 1 to 100 and return next_cursor when another page is available. IP and current-connection lookups accept details=full when raw matched records are needed. Direct RPSL abuse-c and abuse-mailbox values are returned as abuse_contact when present in the daily dataset.

Current connection

Return the address seen by the API and its BGP, allocation, and geofeed record.

Use this for "show my IP" flows. When the API is behind Cloudflare it validates the proxy path before trusting Cloudflare client-IP headers; otherwise it falls back to the raw peer address.

Endpoint
GET /v1/me
Returns
Same compact lookup object as /v1/ip/{address}
curl -sS "https://bgp-api.mehrnet.com/v1/me"
const response = await fetch("https://bgp-api.mehrnet.com/v1/me");
const data = await response.json();
$json = file_get_contents("https://bgp-api.mehrnet.com/v1/me");
$data = json_decode($json, true);
from urllib.request import urlopen
import json

data = json.load(urlopen("https://bgp-api.mehrnet.com/v1/me"))
resp, err := http.Get("https://bgp-api.mehrnet.com/v1/me")
if err != nil {
  log.Fatal(err)
}
defer resp.Body.Close()

var data map[string]any
json.NewDecoder(resp.Body).Decode(&data)
{

  "ip": "1.1.1.1",
  "version": 4,
  "registry": "apnic",
  "network": {"cidr": "1.1.1.0/24", "asn": "AS13335", "as_number": 13335},
  "location": {"country_code": "AU", "region": null, "city": null},

}

IP address lookup

Resolve one IPv4 or IPv6 address into its best matching route, allocation, ASN, and location.

This is the primary service for IP intelligence. The compact response keeps the best route, best allocation, ASN number, location, and source booleans together without exposing every raw candidate by default.

Endpoint
GET /v1/ip/{address}

CIDR prefix lookup

Inspect the allocation covering a prefix and the registered route objects that overlap it.

Use prefix lookup when users click a CIDR or when you need route-object context around a network. It returns the normalized prefix descriptor, covering allocation, and paginated route matches.

Endpoint
GET /v1/prefix?prefix={cidr}
Pagination
limit and cursor apply to route matches

Range lookup is for explicit start/end scans. Use kind=allocations for registry blocks or kind=routes for registered route objects overlapping the same span.

Search lookup

Let the API normalize a user-entered IP, CIDR, or AS number and return the matching resource.

Search is a small normalizer for user input. It returns the canonical query type and endpoint, so clients can redirect to the exact IP, prefix, or ASN resource.

Endpoint
GET /v1/search?q={query}
Recognizes
IP addresses, CIDR prefixes, and ASNs
curl -sS "https://bgp-api.mehrnet.com/v1/search?q=AS13335"
const url = new URL("https://bgp-api.mehrnet.com/v1/search");
url.searchParams.set("q", "AS13335");
const data = await (await fetch(url)).json();
$url = "https://bgp-api.mehrnet.com/v1/search?q=" . rawurlencode("AS13335");
$data = json_decode(file_get_contents($url), true);
from urllib.parse import urlencode
from urllib.request import urlopen
import json

query = urlencode({"q": "AS13335"})
data = json.load(urlopen(f"https://bgp-api.mehrnet.com/v1/search?{query}"))
resp, err := http.Get("https://bgp-api.mehrnet.com/v1/search?q=AS13335")
if err != nil {
  log.Fatal(err)
}
defer resp.Body.Close()

var data map[string]any
json.NewDecoder(resp.Body).Decode(&data)
{
  "query": "AS13335",
  "type": "asn",
  "normalized": "AS13335",
  "endpoint": "/v1/asn/AS13335"
